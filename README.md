# Stock-Price-Forecasting-Using-LSTM-JPFA
Development of a Long Short-Term Memory (LSTM) model to forecast stock prices of PT Japfa Comfeed Indonesia Tbk (JPFA). The project evaluates different hyperparameter configurations using RMSE and MAPE to identify the best-performing model, which is then used for out-of-sample forecasting to project stock prices beyond the available historical data
